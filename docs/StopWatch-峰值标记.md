# StopWatch 峰值标记

转速页和车速页各自记录橙色弧的最高位置。默认开启，短线粗细 10px，径向长度为灰色环的 20px 厚度，使用相同橙色。裁剪在原来的环内，不伸入外圈或中间数字区。

数值回落后，标记固定在最高位置。前 1 秒保持清晰，随后 4 秒淡出，共 5 秒。较低或相等的数值不延长原有计时；超过峰值后更新最高位置，下一次回落重新计时。到期后，以当前数值为下一轮起点，不要求超过已经消失的旧峰值。

峰值取现有滤波后的显示值，与橙色弧端点的百分比和角度一致，不额外读取 OBD。开机扫针、展示模式、无效数据不写入真实峰值。断联、当前参数 5 秒过期、确认 CX 休眠时清除。切页继续按同一个时间戳淡出，回来不会重置计时；峰值仅在对应页面显示时采集。重启后清空临时峰值。

入口：状态页下滑 → RING COLORS → PEAK MARK。使用原来的滚轮选择框设置开关、5/10px、5/10秒。设置保存在原 `statusring` 的三个预留字节里，不改变 blob 大小，不覆盖外圈颜色阈值、车型、BLE 绑定或 CX 待机设置。旧的全零预留字节默认 ON / 10px / 5秒。

RPM 和 SPEED 的灰色弧直径统一为 416px，在 466px 屏幕上采用 5px边距、10px外圈、10px间隔、20px灰环。
