# StopWatch V1.0 无线供电

适用本项目已确认的 StopWatch V1.0，资料核对日期 2026-10-01。

## 接线与选型

无线接收模块必须包含接收线圈、整流及稳压电路，输出固定 DC 5V。建议选能持续输出 5V/1A（5W）的接收模块，配合兼容的发射端；只买裸线圈不能直接供电。额定 1A 是模块可提供的容量，表按负载取电，不会被强制输入 1A。

正极接背面 EXT 总线 14 脚（V1.0 贴纸可能误标 BAT），负极接 11 脚 GND。V1.0.1 同位置已经改为电池端，不适用该接线。保持输出为 5V，不使用未确认输出模式的 9V/12V 快充接收模块。

## 供电检测与唤醒

原理图第 2、4 页给出的路径为：

- USB：VUSB_IN → U2 → 5V_IN → U4 → Internal_5V。
- 背面：Int_5V → U27 CH213K → Internal_5V。
- USB 电压检测 PM_5VIN_ADC 在 5V_IN 上，位于 U4 之前。
- 背面 Int_5V 驱动 Q2，给 PMG4/PORT_INT 输出低有效信号。拔掉背面电源后由常供电 3V3_L0 的电阻上拉，电池不会经 U27 反向造成供电检测误判。

因此原 USB ADC 检测不能覆盖背面供电。固件把 `USB VIN > 4000mV` 或 `PMG4 == LOW` 作为外部电源存在，并为 PMG4 配置下降沿唤醒。使用标准 GPIO 功能（00）及独立 WAKE_EN，不使用数据手册保留的 FUNC=10。

保持现有 CX 状态机：CX 休眠后停止查询及重连，外部电源存在时亮屏；两路外部电源连续消失 3 秒后进入 PMIC L0。背面 5V 恢复、USB 插入或电源键可冷启动。仅供电丢失不会绕过 CX 休眠条件。供电读取或唤醒配置验证失败会阻止自动关机。

## 电流规格的边界

M5Stack 未在产品规格中公布这个背面输入的整机最大连续电流。不能把 USB 电源标称值或电池 450mAh 容量当作该针脚电流额定值。

背面通路 U27 是 CH213K。沁恒 CH213 数据手册标明约 1A 等级的 5V 应用；25°C 电气参数表 Iout 为典型 500mA、上限 900mA。约 1.3A 是典型过流保护阈值，不是允许长期使用的电流。因此 900mA/约 1A 只能描述这个通路芯片的规格，不能保证整机在车内高温下也可持续承载同样电流。

官方列出的电池充电电流默认为 185mA，PMG3 拉低时为 425mA。总输入电流还包含屏幕、主控、BLE、震动、音频等消耗。本次不提高充电电流。5V/1A 接收模块是供电容量建议；实际输入峰值、持续电流和温升需要安装后用电流表测量，不能由电池电压推算。

选型还应确认：对准后的持续 5V 输出能力、车内温度下的降额、低负载时是否自动停输出、以及重新上电能否可靠启动。低负载停电或周期重试可能让 Watch 误以为车辆供电切换，需实际测试。内部电池可承接短暂无线供电波动，但不能替代输入稳定性验证。
