# StopWatch 外圈状态提示

外圈固定为整圈变色，跟随当前页面显示的参数，不闪烁。直径 456px、线宽 10px，在 466px 屏幕上保留约 5px 的外边距。橙色转速弧和原有转速报警闪烁逻辑保持原样。

## 颜色

| 状态 | 颜色 / 行为 |
| --- | --- |
| 初次连接、重连后初始化 | 蓝色 `#55B8FF`；连接后最多留 5 秒等待有效数据 |
| 当前页部分数据过期，但仍有有效 OBD 数据 | 粉色 `#F579B8` |
| 断联清空、初始化结束后没有任何有效 OBD 数据 | 暗灰 `#30343A`；不代表 CX 已休眠，不根据颜色决定关机 |
| CX 进入休眠状态（LP ALERT 或既有后备超时） | 暗灰 `#30343A`；菜单显示 `CX asleep`；停止通信但尚未进入该状态时显示 `Waiting CX sleep` |
| 普通范围 | 白色 `#F4F6F8` |
| 转速中段 / G 值上升 | 绿色 `#43DE77` |
| 接近转速阈值 | 整圈由绿经过黄色平滑过渡至红色 |
| 达到外圈报警阈值 | 红色 `#FF4D4D`，稳定显示 |

这里的渐变指整圈颜色随数值变化，任意时刻整圈保持同一颜色。黄色只用于数值接近报警的过渡，连接状态使用蓝色和粉色。

## 页面行为

- RPM、档位页：按实际 RPM 变色。默认 2400rpm 为绿色，4000rpm 开始向红色过渡，5500rpm 达到红色。1900–2400rpm 从白色过渡到绿色。
- 速度页：复用该参数已有的高值报警设置；没有设置时保持白色，不新增限速值。
- 温度、五参数页：跟随当前配置的项目。启用高值报警后，在阈值最后 10% 区间从白色过渡到橙色，达到阈值变红。多个项目接近报警时，以距离各自阈值最近的项目提示。
- 指针、图表页：跟随当前选择的数据源及它的已有高值报警设置。
- G 表：使用实际 IMU 的横向、纵向合成 G 值，白色逐渐变绿、再经过黄色变红。默认 1.00g 达到红色；这个阈值与白点最外圈的 1.5g 量程分别设置。
- 设置等非数据页：显示连接、过期、休眠状态；正常连接且存在新数据时显示白色。
- 已启用的水温、油温高值报警在数据页有优先级，红色圈下方显示 `CLT HIGH` / `OIL HIGH`。其他当前页高值报警也显示对应参数名称。未启用的温度报警不会自行新增阈值。
- 开机扫针不作为真实车辆报警数据。

## 数据过期

增加独立更新时间记录，不增加 OBD 轮询请求，也不改变既有快照结构。

- RPM、车速、负载、节气门、压力、空燃比等：5 秒未收到有效更新视为过期。
- 水温、进气温度、油温、电压、刹车温度：15 秒未更新视为过期。
- G 值：500ms 未收到有效 IMU 更新视为过期。
- 蓝牙断联、新连接和 LP ALERT 时清除上一会话的数值、滤波历史及更新时间；无效读数显示 `--`，旧读数不参与报警和里程累计。清空只影响显示缓存，不向 CX 熄火策略提供虚构的零转速/零车速。
- 多参数页从未支持的可选项目不单独导致粉色；曾经更新的项目停止更新会触发粉色。正常收到的 0rpm、0km/h 是有效数据。
- 优先级：CX 休眠 > 断联/没有有效数据 > 已启用且仍新鲜的高值报警 > 部分数据过期 > 接近报警 > 普通范围。过期的高温值不能保留红色报警。

## 设置

进入 `SETTINGS → RING COLORS`：

1. `GREEN AT`：转速绿色区。
2. `RED APPROACH`：转速开始向红色过渡。
3. `RED AT`：转速红色区。
4. `G ALERT`：G 值变红阈值，0.50–2.00g。
5. `RING LIGHT`：外圈亮度，10–100%。休眠暗色也受该设置影响。

转速三个阈值之间至少保留 300rpm。滑动时不写 NVS，松手后保存到独立 `statusring` 键，既有用户配置及报警闪烁阈值不迁移。左右滑动或硬件按键返回主设置页。

## 实现与验证

整圈复用一张共享的 456×456 ALPHA8 遮罩，约 203KiB PSRAM。状态最多每 100ms 计算一次，颜色/亮度未变化时不重复修改 LVGL 样式，不使用外圈闪烁动画。外圈亮度通过降低 RGB 值实现，保持圈内不透明，防止原有红黑背景报警透过外圈造成闪烁。

`tools/test_status_ring.c` 验证状态和阈值；项目输出目录内的 LVGL 主机模拟直接编译实际外圈、RPM、主设置页、外圈设置页及缓存代码，仅用桩替代 BLE、硬件时间/同步、NVS 和硬件副作用。

离线检查不能替代 AMOLED 实机观感、真实 CX 休眠和无线供电测试。
